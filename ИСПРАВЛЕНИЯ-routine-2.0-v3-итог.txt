3. ПРЕДЛОЖЕНИЕ ПО GIT HOOKS (Archive Management, раздел «Коммит и проверка hooks»)
======================================================================
Hooks не отключаются и не обходятся: никаких `--no-verify`, `-n`, `-c core.hooksPath=…`, переименования или chmod hooks, `commit --amend`, `revert`, `reset`, `restore`, `checkout`, `clean`, `stash`.
1. Непосредственно перед коммитом (после проверок staged diff) записываются:
   - `STAGED_TREE` = `git write-tree`;
   - `STAGED_NS` = `git -c core.quotepath=false diff --cached --name-status`;
   - `STAGED_SHA` = sha256 от `git diff --cached --binary`;
   - `MSG`.
2. `git commit -m "<MSG>"`, hooks выполняются как обычно.
3. Коммит не создан → СТОП. HEAD должен остаться базовым. В отчёт: вывод hook, сравнение `git write-tree` с `STAGED_TREE`, `git status`. Без повтора и без обхода.
4. Коммит создан → проверка, любое расхождение = СТОП без push:
   a) ровно один новый коммит: `rev-list --count база..HEAD` = 1, `HEAD^` = база;
   b) `HEAD^{tree}` = `STAGED_TREE`;
   c) `diff-tree --no-commit-id --name-status -r HEAD` = `STAGED_NS`, все пути из allowlist, статус соответствует операции;
   d) sha256 от `git diff --binary база HEAD` = `STAGED_SHA`;
   e) `git status --porcelain=v1 --untracked-files=all` пустой (файлы, новые файлы, индекс);
   f) сообщение = `MSG`, без завершающих переводов строки.
5. Перед push `HEAD` = проверенный коммит. После push ls-remote = этот коммит.
6. При расхождении: коммит остаётся локально, отката нет. Полный отчёт только командами чтения. Следующий Preflight остановится на грязном дереве или на том, что локальная `main` впереди `origin/main` и GitHub.
Поведение по отказам:
- pre-commit отклонил → шаг 3: коммита нет, всё как есть, стоп.
- hook изменил файлы → 4e (или шаг 3): стоп, без push.
- hook изменил индекс → 4b, 4c, 4d: стоп, без push.
- commit-msg изменил сообщение → 4f: стоп, без push. Решение: автоматически это не принимается, решает пользовательница (это открытый вопрос, не блокер).
- post-commit изменил или создал файлы → 4e: стоп, без push.
- hook сделал лишний коммит → 4a: стоп, без push.
- несовпадение дерева или состава → 4b, 4c: стоп, без push.
- pre-push отклонил → как отклонённый push: ls-remote, не больше одного повтора при неизменной ветке, коммит остаётся локально.
Dry-run:
- те же шаги (dryrun-prompt, этап 8): агент пишет STAGED_TREE, STAGED_NS, STAGED_SHA и COMMIT_MSG в /workspace/dryrun/report/;
- `--verify` (блок 6a в dryrun-setup.sh) сравнивает HEAD^ с BASE, дерево, состав, sha256 diff и сообщение;
- hooks песочницы — копия hooks настоящего хранилища (cp -a), блокирующий pre-push сохранён.
- Проверено только `bash -n`. Скрипт не запускался.
Изменения в промпте Routine (минимальные):
- в блоке stage 8 добавлены строка о hooks и строка «Гипноз/ только чтение для Routine»;
